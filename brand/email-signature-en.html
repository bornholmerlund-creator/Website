Outlook

  1. Click Copy signature above.
  2. New Outlook / Outlook on the web: Settings → Accounts → Signatures. Classic Outlook: File → Options → Mail → Signatures.
  3. Create a new signature, paste it (Ctrl+V / ⌘V) and save.
  4. Set it as the default for frlu@northbound-data.dk – for both new messages and replies.

Zoho Mail

  1. Go to Settings → Signature and add a new signature.
  2. Click Copy HTML code above, choose Insert HTML (</>) in the editor and paste the code. Pasting the copied signature also works.
  3. Link the signature to frlu@northbound-data.dk and save.
